نظام متكامل لإدارة الأنساب والعائلات العربية بتقنيات حديثة وتصميم فاخر يحاكي برامج سطح المكتب.

**Live Demo**: `npm run dev` ثم افتح `http://localhost:5173`

## ✨ المميزات الرئيسية

### 🌳 إدارة الشجرة
- **3 أوضاع عرض**: شجرة نسب تفاعلية (Tree) + شبكة صور (Grid) + جدول قائمة (List)
- **تنقل سلس**: سحب (Pan) + تكبير/تصغير (Zoom 30%-200%) + ترتيب تلقائي + خريطة مصغرة
- **أجيال مرئية**: شارات ملونة لكل جيل (مؤسسون/أبناء/أحفاد) + خطوط نسب وخطوط زواج متقطعة
- **بحث وفلترة فورية**: حسب الاسم/السنة/المهنة + فلتر ذكر/أنثى/أحياء/متوفون

### 👥 إدارة الأشخاص
- **CRUD كامل**: إضافة شخص، إضافة زوج/زوجة (ربط ثنائي تلقائي)، إضافة ابن (حساب جيل تلقائي + ربط أب/أم)
- **صور شخصية**: رفع صورة (Base64 حتى 2MB) أو رابط URL مع معاينة فورية
- **بيانات غنية**: تاريخ ميلاد، مكان، مهنة، جنسية، هاتف، بريد، مدينة/حي/بريدي، حالة وفاة
- **علاقات ذكية**: عند حذف شخص يتم تنظيف جميع روابط الآباء/الأبناء/الأزواج تلقائياً
- **بطاقة شخص**: شريط جانبي أيسر يعرض كل التفاصيل + روابط عائلية قابلة للنقر (أب، أم، زوجات، أبناء)

### 🏠 إدارة العائلات
- **12 عائلة افتراضية** بألوان مميزة (أزرق، زمردي، كهرماني...)
- إضافة عائلة جديدة باختيار اللون، نقل الأشخاص بين العائلات
- تصفية الشجرة حسب العائلة المختارة أو عرض كل العائلات

### 💾 حفظ ومشاركة
- **تخزين محلي** `localStorage` مع مؤشر حفظ حي (محفوظ/غير محفوظ)
- **تصدير JSON**: تحميل ملف `.familytree` يحتوي كل البيانات
- **استيراد**: فتح ملف JSON سابق
- **طباعة**: دعم طباعة الشجرة + نسخ الأسماء
- Toasts تنبيهات جميلة + تأكيد حذف

### 🎨 تصميم
- RTL كامل، خطوط Tajawal + Cairo
- تدرجات فاخرة Office-style TitleBar + TopInfoBar + Toolbar
- ألوان جنس (ذكر أزرق، أنثى وردي)، شارات جيل، ظلال وطبقات احترافية
- StatusBar غني: نسخة، وقت، حجم، ذاكرة، آخر عملية، إحصائيات أجيال/عائلات/ذكور/إناث/إجمالي
- متجاوب ويدعم وضع الطباعة

## 🧠 نموذج البيانات

```ts
Person {
  id, name, gender, birthYear, birthDate, birthPlace, job, nationality,
  generation, isDeceased,
  fatherId, motherId, spouseIds[], childrenIds[],
  familyId, phone, email, city, neighborhood, postalCode,
  photoUrl (dataURL|null), notes
}
Family { id, name, color, memberIds[] }
```

- الجيل يحسب تلقائياً: ابن = جيل الأب + 1
- الزوج/الزوجة: نفس الجيل + نفس العائلة + ربط spouseIds متبادل

## 🔧 اختصارات مفيدة

- انقر على شخص → يظهر في البطاقة اليسرى
- مرر فوق شخص → تظهر أزرار سريعة (تعديل/زوج/ابن/حذف)
- الشريط الجانبي الأيمن → تبويب أشخاص: انقر لاختيار شخص وتصفية عائلته
- شريط الأدوات → فلترة: يبدل بين الكل/ذكور/إناث/...
- Canvas → اسحب للتنقل، عجلة للزOOM، زر ملاءمة للشاشة يعيد الضبط
